## Kayky Paschoal Ribeiro - RM99929

## Descrição do Projeto

O projeto **"Marcação de Consultas Médicas"** é um aplicativo mobile desenvolvido em **React Native com TypeScript**, voltado para facilitar o agendamento de consultas médicas. Ele permite que usuários realizem login, se cadastrem, agendem, visualizem e gerenciem consultas de forma prática. Durante o desenvolvimento, foram realizadas refatorações como a reorganização da estrutura de pastas, modularização de componentes reutilizáveis, aplicação da tipagem estática com TypeScript e melhorias na legibilidade do código, seguindo boas práticas de desenvolvimento.
